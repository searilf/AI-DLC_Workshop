# Step 01 — Environment Setup (0–10 min)

## Objective
ยืนยันว่า Harness และ AI-DLC Workflow พร้อม ก่อนเริ่มโจทย์

## Instructions
1. เปิด [Mission](../mission.md) แล้วให้สมาชิกทีมอ่านร่วมกัน
2. ยืนยันการเลือกหนึ่ง Harness: Kiro, Claude Code หรือ Codex CLI
3. ตรวจว่า AI-DLC integration ได้ตั้งค่าและทดสอบก่อน Workshop แล้ว
4. สร้าง Working Directory **แยกจาก Guide Repository**
5. เปิด Workflow ผ่านวิธีที่ถูกต้องสำหรับ Harness/Version ของทีม

## Expected Output
- AI-DLC Workflow เริ่มได้จริง
- Project Workspace พร้อมสร้าง Application
- ทีมทราบหน้าที่ตาม [Roles](../roles.md)

## Checkpoint
- [ ] Harness ใช้งานได้
- [ ] Workflow พร้อมและเปิดได้
- [ ] ทั้งทีมเข้าใจ Mission
