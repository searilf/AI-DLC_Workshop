# Step 04 — Implementation (35–55 min)

## Objective
ให้ AI-DLC ช่วยพัฒนา Working Prototype ตาม Plan โดยทีมตรวจ Code และผลการทำงาน

## Instructions
1. ให้ AI เริ่มจาก App Skeleton และ Minimum Features
2. ให้ Developer ตรวจ Code Structure/Dependencies ที่สร้าง
3. รัน Application ในเครื่องตามคำแนะนำของ Stack ที่ทีมเลือก
4. ตรวจ Create Incident → View List → Update Status → Priority
5. หากพบปัญหา ให้ AI ช่วยวิเคราะห์และแก้ทีละจุด
6. **อย่าเพิ่ม Feature ใหม่** ถ้า Minimum Features ยังไม่ครบ

## Example Prompt
> ดำเนินการ Implementation ตามแผนที่ทีมอนุมัติแล้ว ให้ทำ Minimum Features ก่อน และแสดงวิธีรันและตรวจสอบผลจริงหลังการเปลี่ยนแปลงสำคัญ แจ้งสิ่งที่ต้องให้ทีมตัดสินใจหากมี Trade-off

## Implementation Review
- Code ถูกสร้างใน Project Workspace ที่ถูกต้องหรือไม่?
- มี Dependency ที่ไม่จำเป็นหรือไม่?
- มีการบันทึก Data จริงหรือ Hardcode เฉพาะ Demo?
- ถ้ารันไม่ได้ เกิดจากอะไร?

## Expected Output
Application Prototype ที่เปิดได้ หรือความคืบหน้าที่มีหลักฐานชัดเจน

## Checkpoint
- [ ] รัน App ได้หรือบันทึก Blocker
- [ ] ตรวจ Feature ตาม MVP
- [ ] Developer อธิบาย Code ที่ AI สร้างได้
