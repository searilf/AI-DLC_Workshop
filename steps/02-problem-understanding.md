# Step 02 — Problem Understanding (10–20 min)

## Objective
ฝึกให้ AI ตั้งคำถามและให้ทีมระบุ Scope ก่อนสร้าง Code

## Instructions
1. อ่าน [Business Scenario](../mission.md)
2. เริ่ม Intent หรือกระบวนการที่เทียบเท่าผ่าน AI-DLC Workflow
3. อธิบายปัญหาโดย **ยังไม่สั่งให้สร้าง App**
4. ให้ AI สรุปสิ่งที่ทราบและถามความต้องการที่ยังไม่ชัด
5. ให้ PO ตอบคำถามและทีมตกลง MVP

## Example Prompt
> เราต้องการสร้าง IT Incident Management Application ภายใน Workshop 70 นาที กรุณาใช้ AI-DLC Workflow เพื่อทำความเข้าใจปัญหาและถามคำถามสำคัญทีละเรื่องก่อนเริ่มออกแบบหรือเขียน Code รอการยืนยันจากทีมก่อนดำเนินการต่อ

## Team Discussion
- ใครคือผู้ใช้?
- ควรมี Field อะไรใน Incident?
- อะไรจำเป็นสำหรับ MVP และอะไรไว้ทำภายหลัง?
- ข้อมูลต้องอยู่หลัง Restart หรือไม่?

## Expected Output
Problem Statement, MVP Scope, Open Questions และ Human Decision

## Checkpoint
- [ ] ระบุผู้ใช้และปัญหาได้
- [ ] ทีมตอบคำถาม AI แล้ว
- [ ] ทุกคนเห็นชอบ MVP
