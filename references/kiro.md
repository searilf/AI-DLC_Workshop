# Kiro — Harness Guide

## Before Lab
- ติดตั้งและล็อกอิน Kiro
- ติดตั้ง/configure AI-DLC Workflows ตามเอกสารที่รองรับเวอร์ชันของ Kiro
- ทดลองเริ่ม Intent/Workflow ใน Project ทดสอบ

## During Lab
1. เปิด Working Directory
2. เริ่ม AI-DLC Workflow
3. ให้ AI ถาม Requirement ก่อนสร้าง Code
4. Review Design/Plan ก่อน Implementation
5. ทดสอบและบันทึกหลักฐานที่ได้จริง

**Verify:** ตรวจว่ามี AI-DLC Workflow/Artifacts จริง ไม่ใช่เพียงใช้ Kiro สนทนาเขียน Code

เอกสาร: https://github.com/awslabs/aidlc-workflows และ https://kiro.dev/
