# Claude Code — Harness Guide

## Before Lab
- ติดตั้งและล็อกอิน Claude Code
- ติดตั้ง/configure AI-DLC Workflows ที่รองรับ Claude Code
- ทดลองเปิด Project และเริ่ม Workflow ล่วงหน้า

## During Lab
1. เปิด Claude Code ที่ Working Directory ของทีม
2. เริ่ม AI-DLC Workflow ด้วย Entry Point ของเวอร์ชันที่ติดตั้ง
3. ทำความเข้าใจโจทย์และตอบ Clarifying Questions
4. Review Design และ Plan ก่อน Build
5. Run/Test/Review พร้อมบันทึก Human Decisions

**Verify:** ต้องมีหลักฐานการใช้ AI-DLC Workflow ไม่ใช่ Generic Claude Chat

เอกสาร: https://github.com/awslabs/aidlc-workflows และ https://code.claude.com/docs/
