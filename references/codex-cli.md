# Codex CLI — Harness Guide

## Before Lab
- ติดตั้งและล็อกอิน Codex CLI
- ติดตั้ง/configure AI-DLC Workflows สำหรับ Codex CLI
- ทดลองเริ่ม Workflow ใน Project ทดสอบ

## During Lab
1. เปิด Codex CLI ใน Working Directory ของทีม
2. เริ่ม AI-DLC Workflow ผ่านวิธีที่รองรับ
3. ให้ AI สำรวจ Requirement และถามคำถาม
4. Review Architecture/Plan ก่อน Implementation
5. Test จริงและบันทึกผล

**Verify:** ต้องแยก AI-DLC Workflow จากการใช้ Codex เขียน Code แบบทั่วไป
