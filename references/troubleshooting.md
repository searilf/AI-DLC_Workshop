# Troubleshooting

## Harness เปิดไม่ได้
ตรวจการ Login, Network, Installation, Version และสิทธิ์ที่ต้องใช้ หากยังไม่พร้อมอย่าอ้างว่าเริ่ม AI-DLC Workflow สำเร็จ

## AI เริ่มเขียน Code ทันที
หยุดและขอให้ AI ย้อนกลับมาทำความเข้าใจ Requirements ก่อน

## AI สร้าง Architecture ซับซ้อน
ถามว่าอะไรคือ MVP Minimum และมีทางเลือกที่ติดตั้ง/ทดสอบง่ายกว่าหรือไม่

## Application รันไม่ได้
เก็บ Error Message จริง ขอให้ AI วิเคราะห์ Root Cause ทีละข้อ และลองแก้ใน Scope ที่จำกัด

## Test Failed
บันทึก Failed ตามจริง อย่าลบ Test เพียงเพื่อให้ผลลัพธ์เป็นสีเขียว

## AI-DLC Artifacts ไม่ปรากฏ
ตรวจว่าได้เริ่ม Workflow จริงและอ่านเอกสาร Integration/Version ที่ตรงกับเครื่อง
