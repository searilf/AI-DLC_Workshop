# Final Submission Checklist

- [ ] Working Prototype หรือ Progress Evidence
- [ ] อธิบายการเริ่ม AI-DLC Workflow ได้
- [ ] มี Requirements / Design Artifacts ที่เกี่ยวข้อง
- [ ] สรุป Technology Stack และเหตุผลที่เลือก
- [ ] มีผล Test Passed / Failed / Not Run
- [ ] มี Human Decisions อย่างน้อย 2 เรื่อง
- [ ] กรอก [Team Summary](../templates/team-summary.md)
- [ ] เตรียม [Showcase](showcase-guide.md)
