# AI-DLC Hands-on Workshop — Team Challenge

**ภาษา:** ไทย | **Hands-on:** 70 นาที | **รูปแบบ:** ทีมละ 4 คน | **โจทย์:** IT Incident Management Application

## เป้าหมาย
ทดลองใช้ **AI-Driven Development Lifecycle (AI-DLC)** เพื่อเปลี่ยนปัญหาธุรกิจให้เป็น Working Prototype ผ่านการทำความเข้าใจความต้องการ ออกแบบ พัฒนา และทดสอบ โดย **AI ช่วยขับเคลื่อนงาน ทีมเป็นผู้ตัดสินใจ**

> Repository นี้เป็น **Workshop Guide** ไม่ใช่ Starter Application และไม่มี Source Code เฉลย

## กติกา
- เลือกหนึ่ง Harness: **Kiro, Claude Code หรือ Codex CLI** พร้อม AI-DLC Workflows ที่ติดตั้งและตรวจสอบล่วงหน้า
- ให้ AI ถามและวางแผนก่อนเริ่มเขียน Code; ทีมตรวจคำตอบและยืนยันทางเลือก
- เลือก Technology Stack ที่เรียบง่ายและเหมาะกับเวลา
- **Step ในคู่มือนี้เป็น Learning Milestone** ไม่ใช่ชื่อ Stage ภายใน AI-DLC และไม่จำเป็นต้องตรงกันทุกข้อ
- บันทึก Human Decisions อย่างน้อยสองรายการ และอย่าอ้างว่าทดสอบผ่านโดยไม่ได้รันจริง
- ไม่มี Facilitator Gate, Hidden Test หรือ Change Request ระหว่าง Lab
